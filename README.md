# IELTS Placement Test - Interactive Desktop & PWA Assessment

تطبيق تفاعلي متكامل لاختبار تحديد المستوى لـ IELTS والمبني وفق نظام التقييم القائم على اليقين (**Certainty-Based Marking - CBM**).

---

## 🌟 أبرز المميزات المنفذة بدقة

1. **تسجيل بيانات الطالب:**
   - شاشة تسجيل واضحة (الاسم الكامل، رقم الهاتف / واتساب، البريد الإلكتروني).
   - عرض إرشادات الامتحان ونظام Sure / Not sure.

2. **بيئة الامتحان التفاعلية:**
   - 60 سؤالاً مأخوذة بالكامل من الاختبار الرسمي ومقسمة إلى 4 مستويات:
     - Part 1: Foundational English & Structure (Q1 - Q15)
     - Part 2: Intermediate Grammar & Expressions (Q16 - Q30)
     - Part 3: Academic Vocabulary & Context (Q31 - Q45)
     - Part 4: Advanced Academic English (Q46 - Q60)
   - خيارات الإجابة (A, B, C, D) مع زري اليقين لكل سؤال: `[ ✓ Sure ]` و `[ ? Not sure ]`.
   - **مؤقت تنازلي دقيق:** 59 دقيقة مع إنذار لوني في آخر 5 دقائق وإغلاق تلقائي عند انتهاء الوقت.
   - **لوحة تنقل بالأسئلة (Question Palette):** تمكن الطالب من مراجعة الأسئلة وتحديد المعلمة بعلم (Flagged).

3. **حساب وتتبع الوقت لكل سؤال بدقة (Question-by-Question Timing):**
   - يسجل البرنامج عدد الثواني التي قضاها الطالب في كل سؤال على حدة، بالإضافة إلى الوقت الإجمالي للاختبار لتحليل سرعة الحل (Pacing).

4. **إخفاء النتيجة عن الطالب:**
   - بمجرد انتهاء الاختبار أو نفاد الوقت، تظهر رسالة شكر وتأكيد استلام رسمي تفيد بأن النتيجة سرية وسيتم التواصل معه هاتفياً بواسطة المدرس لتحديد مستواه.

5. **بوابة المدرس / الإدارة المحمية بكلمة سر (Instructor Portal):**
   - دخول سري عبر زر "Instructor Portal 🔒" بأعلى الصفحة.
   - **بيانات الدخول الافتراضية:**
     - اسم المستخدم: `admin`
     - كلمة السر: `admin123`
   - إمكانية **تغيير اسم المستخدم وكلمة السر** في أي وقت من داخل لوحة التحكم.
   - إمكانية **التحكم في مدة الاختبار** (مثلاً تغييرها من 59 دقيقة إلى 45 دقيقة أو 60 دقيقة).

6. **تقرير تشخيصي شامل وتحليلي للطالب (Diagnostic Report):**
   - الدرجة الخام (Raw Score) والنسبة المئوية.
   - درجة CBM المعدلة وفق اليقين.
   - تقدير IELTS Band التقريبي (مثلاً: 7.5 - 8.0) والمستوى الأوروبي المشترك (CEFR C1).
   - مصفوفة اليقين الرباعية (CBM 4-Quadrant Analysis):
     - **Solid Mastery (Correct + Sure):** المعرفة الراسخة.
     - **Lucky Guesses (Correct + Not Sure):** تخمينات موفقة تحتاج تثبيت.
     - **Misconceptions (Incorrect + Sure):** مفاهيم خاطئة وثقة مفرطة زائفة (تنبيه باللون الأحمر).
     - **Recognized Gaps (Incorrect + Not Sure):** ثغرات أقر بها الطالب بوعي.
   - تحليل زمني: متوسط وقت السؤال، أطول سؤال استغرق وقتاً، وأسرع سؤال.
   - جدول تفصيلي كامل لكل سؤال (المهارة، إجابة الطالب، الإجابة الصحيحة، الوقت المستغرق بالثانية، ومستوى اليقين).

7. **تصدير وحفظ التقارير:**
   - **طباعة التقرير أو حفظه كـ PDF رسمي** بنقرة زر واحدة (`Print / Save PDF`).
   - **تصدير كملف CSV / Excel** لكل طالب على حدة أو لكل الطلاب مجتمعين.

## 🚀 طرق التشغيل والاستخدام

### الطريقة 1: التشغيل المباشر الفوري (أسهل وأسرع طريقة)
1. افتح المجلد:
   `C:\Users\user\.gemini\antigravity\scratch\ielts-placement-app`
2. انقر نقراً مزدوجاً على الملف `index.html`.
3. سيعمل التطبيق فوراً في المتصفح بكامل ميزاته وبدون الحاجة لأي اتصال بالإنترنت!

### الطريقة 2: تثبيته كتطبيق سطح مكتب (PWA)
1. افتح الملف `index.html` في متصفح Microsoft Edge أو Google Chrome.
2. ستظهر أيقونة صغيرة في شريط العنوان بالأعلى على شكل شاشة أو علامة (+): **"تثبيت التطبيق" (Install App)**.
3. اضغط عليها وسيتم تثبيته كبرنامج مستقل على سطح المكتب وقائمة Start يعمل في نافذة مستقلة دون أشرطة المتصفح.

### الطريقة 3: تشغيله عبر Electron
إذا كان لديك Node.js وترغب بتشغيله أو تصديره كـ `.exe`:
```bash
cd "C:\Users\user\.gemini\antigravity\scratch\ielts-placement-app"
npm install
npm start
```
وللتصدير إلى ملف تنفيذي للويندوز:
```bash
npm run dist
```
